# Student Guide - Using LearnFlow

Welcome to LearnFlow! This guide will help you get started with learning Python.

---

## Getting Started

### 1. Create Account

Visit **http://localhost:3001** and click **Sign Up**

### 2. First Steps

1. Take the **Placement Quiz** to assess your current knowledge
2. Start with **Python Basics** module
3. Complete exercises to earn points

### 3. Learning Dashboard

Your dashboard shows:
- **Mastery Score**: Overall progress (0-100%)
- **Module Progress**: Track completion of each module
- **Learning Streak**: Consecutive days of activity
- **Points Earned**: From completed exercises

---

## How Learning Works

### Mastery Levels

Your mastery is calculated from:
- **Exercises Completed** (40% weight)
- **Quiz Performance** (30% weight)
- **Code Quality** (20% weight)
- **Learning Streak** (10% weight)

### Adaptive Content

LearnFlow adapts explanations to your level:

| Mastery Level | Content Style | Example |
|---------------|---------------|---------|
| **Beginner** (0-40%) | Simple explanations, basic examples | `x = 5` with comments explaining each part |
| **Learning** (41-70%) | More detailed, practical context | Real-world analogies, use cases |
| **Proficient** (71-90%) | Concise, assumes knowledge | Best practices, performance tips |
| **Mastered** (91-100%) | Minimal, expert-level | Design patterns, optimization |

### Progressive Hints

When you're stuck:
1. **Hint 1**: General guidance without giving answer
2. **Hint 2**: More specific direction
3. **Hint 3**: Nearly complete solution

This builds problem-solving skills!

## Taking Exercises

### Exercise Flow

1. **Read Instructions**: Each exercise has clear requirements
2. **Write Code**: Use the in-browser Monaco editor
3. **Test Your Code**: Click "Run" to execute
4. **Submit**: Click "Submit" to grade
5. **Get Feedback**: Instant feedback on your code

### Code Execution

- **Sandboxed**: Your code runs in isolated environment
- **Safe**: Can't access files or network (security)
- **Fast**: Results in under 5 seconds
- **Interactive**: Can use input() for I/O exercises

### Getting Stuck?

1. **Check Hints**: Click "Show Hint" for progressive guidance
2. **Request Help**: Use chat to ask your AI tutor
3. **Review Examples": Check solution tab for reference

## AI Tutor Chat

### Getting Help

Click the chat icon in the sidebar to ask questions:

```
Examples:
- "What is a variable?"
- "How do I fix NameError?"
- "Explain for loops"
- "Why is my code running slowly?"
```

### What the AI Can Do

- Explain Python concepts at your level
- Debug your code without giving answers
- Suggest improvements for your code
- Recommend next exercises
- Track your struggles and notify teachers

### Good Questions

**Specific questions work best:**
- ❌ "My code doesn't work" → Be more specific
- ✅ "I get 'NameError: name 'x' not defined' when running my code" → Good!

## Tips for Success

### 1. Practice Every Day

Consistency beats intensity - 15 minutes/day > 3 hours/week

### 3. Ask for Help

The AI tutor is patient! No question is too basic.

### 4. Use the Chat Interface

Chat to:
- Get unstuck on exercises

- Get recommendations on what to learn next

### 5. Review Solutions

After submitting, check the solution tab to understand better approaches.
